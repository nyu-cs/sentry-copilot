# Strategy catalog data

This directory currently contains only synthetic catalog fixtures.

- `demo.synthetic_covenant_latter/` is invented test data.
- Its strategy IDs, names, descriptions, HP values, revision differences, and SVG icons do not
  represent game content.
- `support-targets.yaml` declares product targets only. It contains no validated-support claim and
  no real strategy catalog.
- Real or third-party game assets must remain under ignored private storage and must not be copied
  into this public directory without an approved source and distribution policy.
